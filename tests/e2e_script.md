# 🎬 E2E Test Script — Telegram Intake Bot

## Подготовка

1. Убедись, что бот запущен по [`DEPLOYMENT_GUIDE.md`](../docs/DEPLOYMENT_GUIDE.md).
2. Подготовь тестовый Telegram-аккаунт и тестовый чат операторов (`OPERATOR_CHAT_ID`).
3. Убедись, что у бота есть право отправлять сообщения в чат операторов.
4. Открой мобильное или десктопное приложение Telegram на тестовом аккаунте.

---

## Сценарий A — Заявка в техподдержку

### Цель

Проверить, что бот собирает все поля заявки и отправляет структурированное сообщение в чат операторов.

### Шаги

| # | Действие тестировщика | Ожидаемый ответ бота |
|---|-----------------------|----------------------|
| A1 | Отправить `/start` | Меню выбора сценария с вариантами `1` и `2` |
| A2 | Отправить `1` | Приветствие сценария техподдержки + запрос имени |
| A3 | Отправить `Александр` | Запрос контакта |
| A4 | Отправить `+79991234567` | Запрос описания проблемы |
| A5 | Отправить `Не включается ноутбук после обновления` | Запрос времени возникновения |
| A6 | Отправить `сегодня утром` | Запрос места/локации |
| A7 | Отправить `на ноутбуке` | Запрос приоритета |
| A8 | Отправить `срочно` | Финальное сообщение о передаче заявки специалисту |
| A9 | Перейти в чат операторов | Видеть структурированную заявку с именем, контактом, проблемой, временем, местом, приоритетом, Telegram ID/username |

### Критерии прохождения

- Все шаги A1–A8 завершены без ошибок.
- В чате операторов появилось сообщение от имени бота.
- Все поля заявки заполнены корректно.

## Сценарий B — Сбор лида для отдела продаж

### Цель

Проверить, что бот собирает обязательные поля лида, квалифицирует статус и отправляет заявку в чат продаж.

### Шаги

| # | Действие тестировщика | Ожидаемый ответ бота |
|---|-----------------------|----------------------|
| B1 | Отправить `/start` | Меню выбора сценария |
| B2 | Отправить `2` | Приветствие сценария продаж + запрос имени |
| B3 | Отправить `Алексей` | Запрос контакта |
| B4 | Отправить `@alexei_sales` | Запрос компании (необязательный) |
| B5 | Отправить `ООО Ромашка` | Запрос интересующей услуги |
| B6 | Отправить `Автоматизация продаж через Telegram-бота` | Запрос бюджета |
| B7 | Отправить `100–200 тыс. руб.` | Запрос сроков |
| B8 | Отправить `В течение недели` | Финальное сообщение о передаче заявки менеджеру |
| B9 | Перейти в чат продаж | Видеть структурированный лид с именем, контактом, компанией, интересом, бюджетом, сроками, статусом, Telegram ID/username |

### Критерии прохождения

- Все шаги B1–B8 завершены без ошибок.
- В чате продаж появилось сообщение от имени бота.
- Все обязательные поля заполнены; статус определён (`горячий` / `теплый` / `холодный`).

## Сценарий C — Сброс диалога

### Цель

Проверить, что команда `/reset` очищает текущую сессию и возвращает пользователя к выбору сценария.

### Шаги

| # | Действие тестировщика | Ожидаемый ответ бота |
|---|-----------------------|----------------------|
| C1 | Отправить `/start` и выбрать `1` | Начало диалога техподдержки |
| C2 | Отправить `Александр` | Запрос контакта |
| C3 | Отправить `/reset` | Сообщение о сбросе + меню выбора сценария |
| C4 | Отправить `2` | Начало диалога сбора лидов |

### Критерии прохождения

- После `/reset` бот не продолжает старый диалог техподдержки.
- Бот показывает меню `/start` заново.
- Можно начать другой сценарий с чистого листа.
