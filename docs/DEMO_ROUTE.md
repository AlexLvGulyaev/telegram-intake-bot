# Маршрут проверки демо — Telegram Intake Bot

Как быстро убедиться, что приём заявок работает: пройти диалог бота
до зарегистрированной заявки и посмотреть, что видит оператор.

## Маршрут проверки

1. **Открыть** [бота в Telegram](https://t.me/PEcb06_bot) →
   **отправить** /start → **выбрать** направление: техподдержка или
   заявка для отдела продаж.
2. **Пройти** диалог по вопросам бота (имя → проблема → когда
   началась → где проявляется → приоритет) → **увидеть**, что отвечать
   можно свободным текстом: значения полей бот извлекает из ваших
   формулировок.
3. **Пропустить** какое-нибудь обязательное поле → **увидеть**
   уточняющий вопрос в правильном порядке: детерминированная защита не
   выпускает заявку без обязательных полей.
4. **Завершить** диалог («Спасибо! Я передал вашу заявку специалисту»)
   → **открыть** документацию оператора и посмотреть пример заявки в
   чате операторов: структурированная карточка с полями из диалога.

## Что ещё доступно
