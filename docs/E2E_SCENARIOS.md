## 🎯 1. Назначение

Этот документ содержит сквозные бизнес-сценарии Telegram Intake Bot без технических деталей. Используйте его для ручного E2E-тестирования, демонстрации заказчику и подготовки скриншотов.

---

## 🎬 2. Сценарий 1 · Заявка в техподдержку

### 2.1. Цель

Клиент оформляет обращение в техподдержку через Telegram-бота. Заявка приходит в чат операторов.

### 2.2. Шаги

1. Клиент отправляет боту `/start`.
2. Бот предлагает выбрать сценарий.
3. Клиент пишет `1`.
4. Бот приветствует и спрашивает имя.
5. Клиент: `Александр`.
6. Бот запрашивает контакт.
7. Клиент: `+79991234567`.
8. Бот спрашивает, что случилось.
9. Клиент: `Не включается ноутбук после обновления`.
10. Бот спрашивает, когда возникла проблема.
11. Клиент: `сегодня утром`.
12. Бот уточняет, где проявляется.
13. Клиент: `на ноутбуке`.
14. Бот спрашивает приоритет.
15. Клиент: `срочно`.
16. Бот: `Спасибо! Я передал вашу заявку специалисту...`
17. В чат операторов приходит структурированная заявка.

### 2.3. Ожидаемый результат в чате операторов

```text
=== НОВАЯ ЗАЯВКА В ТП ===

Имя: Александр
Контакт: +79991234567

Проблема:
Не включается ноутбук после обновления

Когда возникло: сегодня утром
Где: ноутбук

Приоритет: срочно

Telegram user id: 331349444
Telegram username: @alex_example

=== КОНЕЦ ===
```

## 🎬 3. Сценарий 2 · Сбор лида для отдела продаж

### 3.1. Цель

Потенциальный клиент оставляет заявку для отдела продаж. Лид квалифицируется и приходит в чат менеджеров.

### 3.2. Шаги

1. Клиент отправляет боту `/start`.
2. Бот предлагает выбрать сценарий.
3. Клиент пишет `2`.
4. Бот приветствует и спрашивает имя.
5. Клиент: `Алексей`.
6. Бот запрашивает контакт.
7. Клиент: `@alexei_sales`.
8. Бот спрашивает компанию.
9. Клиент: `ООО Ромашка`.
10. Бот спрашивает, какая услуга интересует.
11. Клиент: `Автоматизация продаж через Telegram-бота`.
12. Бот уточняет бюджет.
13. Клиент: `100–200 тыс. руб.`.
14. Бот спрашивает сроки.
15. Клиент: `В течение недели`.
16. Бот квалифицирует как `теплый`.
17. Бот: `Спасибо! Я передал вашу заявку менеджеру...`
18. В чат продаж приходит структурированный лид.

### 3.3. Ожидаемый результат в чате операторов

```text
=== НОВЫЙ ЛИД ===

Имя: Алексей
Контакт: @alexei_sales
Компания: ООО Ромашка

Интерес:
Автоматизация продаж через Telegram-бота

Бюджет: 100–200 тыс. руб.
Сроки: В течение недели
Статус: теплый

Telegram user id: 331349444
Telegram username: @alexei_sales

=== КОНЕЦ ===
```

## 🎬 4. Сценарий 3 · Сброс диалога

### 4.1. Цель

Клиент начинает диалог, но решает начать заново.

### 4.2. Шаги

1. Клиент проходит несколько шагов любого сценария.
2. Отправляет `/reset`.
3. Бот сбрасывает сессию и снова показывает меню выбора.

### 4.3. Ожидаемый результат

Бот возвращается к выбору сценария, все ранее собранные данные удаляются.

### 5.1. Правила хорошего скриншота

- Не обрезайте заголовок чата — важно видеть имя бота.
- Включите строку ввода только если на ней есть значимый текст.
- Для скринов результатов в чате операторов важно видеть время получения сообщения и имя бота-отправителя.
- Анонимизируйте личные данные реальных пользователей; используйте тестовые аккаунты.

### 5.2. Где сохранять

- Исходные PNG: `docs/screenshots/` в исходном кейсе.
- В публичный репозиторий `AlexLvGulyaev/telegram-intake-bot` загружаются только после верификации содержимого.
