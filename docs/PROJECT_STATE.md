## 🎯 1. Project Summary

Telegram-бот для первичной обработки входящих заявок. Бот ведёт диалог с клиентом, собирает обязательные поля заявки в техподдержку или лида для отдела продаж, извлекает данные из свободного текста через LLM (OpenAI API) и отправляет структурированную заявку в Telegram-чат операторов.

**Ключевые параметры:**

| Параметр | Значение |
|----------|----------|
| Канал | Telegram |
| Язык | Python 3.12, aiogram 3.x |
| LLM | OpenAI API с JSON Schema ответа |
| Хранилище сессий | In-memory (MVP) |
| Контейнеризация | Docker |
