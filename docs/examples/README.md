## 🎯 1. Назначение

Каталог содержит примеры JSON-ответов LLM и итоговых сообщений, отправляемых в чат операторов.

| Файл | Содержимое |

| `support_ticket_message.txt` | Пример итогового сообщения заявки в ТП |
