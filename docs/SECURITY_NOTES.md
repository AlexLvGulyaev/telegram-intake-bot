## 🎯 1. Секреты и переменные окружения

Все чувствительные параметры хранятся в файле `.env`:

| Переменная | Назначение |
|------------|------------|
| `TELEGRAM_BOT_TOKEN` | Токен доступа бота к Telegram Bot API |
| `OPENAI_API_KEY` | Ключ доступа к OpenAI API |
| `OPERATOR_CHAT_ID` | ID чата, куда отправляются заявки |

**`.env` не должен попадать в Git-репозиторий.**

Файл `.env.example` содержит placeholder'ы и используется как шаблон.

---

## 🔍 2. Проверка перед публикацией

Убедитесь, что в репозитории нет:

- реального `TELEGRAM_BOT_TOKEN`;
- реального `OPENAI_API_KEY`;
- реальных `OPERATOR_CHAT_ID` в логах;
- файлов `.env`;
- комментариев с примерами рабочих ключей.

---

## 🛡️ 3. Рекомендации для production

| Рекомендация | Почему важно |
|--------------|--------------|
| Ограничьте доступ к серверу по SSH | Защита от несанкционированного управления |
| Используйте постоянное хранилище для сессий и аудита | История не теряется при перезапуске |
| Настройте ротацию логов | Контроль дискового пространства |
| Регулярно обновляйте образ Docker | Исправление уязвимостей |
| Используйте отдельный API-ключ для бота | Ограничение зоны компрометации |

---

## 📝 4. Обработка данных

- Бот не логирует полный текст сообщений пользователей в продакшене (по умолчанию логирует только технические события).
- В тестовых примерах используйте синтетические или анонимизированные данные.
